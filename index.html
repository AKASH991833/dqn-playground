Honest limits

  • DQN is stochastic: some runs learn in 80 episodes, some need 300, some diverge. That instability is real deep RL, not a bug - reset and retrain, or lower the learning rate.
  • Training in a browser tab is slower than a GPU server; 150 episodes takes a few minutes.
  • CartPole is the "hello world" of control. Real problems need bigger networks and more machinery.
